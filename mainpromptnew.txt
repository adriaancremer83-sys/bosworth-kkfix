QR CODE SCAN TRACKING
═══════════════════════════════════════

When QR code is scanned and page loads:
Silently capture:
1. Timestamp
2. Geolocation — request browser permission
   - If granted: lat/lng → reverse geocode 
     to city/region (use ipapi.co)
   - If denied: IP-based location via 
     https://ipapi.co/json/
3. Device type (mobile/tablet/desktop)
4. User agent
5. Batch ID from URL parameter:
   ?batch=BSW-2024-001&unit=PKG-0042

Supabase table: qr_scans
Fields: id, timestamp, lat, lng, city, 
region, country, device_type, user_agent, 
batch_id, unit_id, ip_address
